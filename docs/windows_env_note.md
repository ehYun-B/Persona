# Windows 환경 기록 노트

이 문서는 로컬 LLM 연구 프로토타입 실행 환경을 기록하기 위한 파일입니다.
아래 명령어를 PowerShell에서 실행하고, 결과를 필요한 시점에 이 문서 아래에 붙여넣으세요.

## 기록할 명령어

```powershell
systeminfo
python --version
pip --version
git --version
ollama --version
ollama list
nvidia-smi
```
