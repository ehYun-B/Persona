# 비선호시설 주민 숙의 연구 앱

실행 파일: `dist\ResidentDeliberationResearch\ResidentDeliberationResearch.exe`

1. 시설·지역에서 템플릿을 고르거나 시설명을 직접 입력한다.
2. 주요 쟁점과 최초 사업자 제안을 연구자가 검토한 문장으로 저장한다.
3. 설문·군집에서 CSV/Excel 설문 파일을 올리고, 9개 필수 태도 항목을 열에 연결한다.
4. 군집 수 후보 범위를 정해 K-means 분석을 실행한다. 실루엣, Calinski-Harabasz, Davies-Bouldin, Ward-K-means ARI, 재표본 ARI를 함께 확인한다.
5. 주민 패널에서 군집별 대표·갈등 민감·조건부 수용 응답자를 뽑고, 입력 지역과 정확히 일치하는 NVIDIA Nemotron-Personas-Korea 배경 서사를 결합한다.
6. 주민 토론에서 사회자 진행, 수정안, 전원 중간점검과 최종 확인을 실시간으로 확인한다. 최종 확인이 전원 `confirm`일 때만 가결로 기록된다.

## 설문 입력 원칙

- 필수 태도 항목: 위험 인식, 편익 인식, 분배 공정성, 절차 공정성, 신뢰, 장소 애착, 사회적 영향, 조건부 수용, 갈등행동 가능성.
- 보상 선호 8개 항목은 선택이다. 없으면 중립값으로 기록되므로, 실제 보상 선호를 해석하려면 해당 문항을 설문에 포함해야 한다.
- 1~5점 지표와 1~7점 Likert 응답을 모두 받을 수 있다. 1~7점은 내부에서 1~5점으로 선형 변환한 뒤 표준화하여 분석한다.

## 해석 경계

- 전국 표본으로 만든 군집은 전국의 태도 유형이다. 지역 선택은 지역 대표 표본을 뜻하지 않고, 배경 서사를 위한 **지역 맥락 시뮬레이션**이다.
- NVIDIA 페르소나는 성별·연령·직업·생활 배경의 서사 재료이며, 시설 수용 태도는 설문 군집 결과로만 부여한다.
- 토론의 최종안은 가상 패널이 수용한 조건 묶음이다. 실제 주민 합의, 법적 의결, 또는 금전 보상액의 예측으로 제시하지 않는다.
- 시설별 결론을 비교하려면 시설별 위험·편익·수용조건 문항을 설문에 포함하고, 같은 분석 절차를 반복해야 한다.
